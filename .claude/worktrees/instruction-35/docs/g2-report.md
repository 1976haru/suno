§8-1은 "각 워크스페이스에서 6곡씩, 총 24곡"이라고 적었지만 5(워크스페이스) × 6(곡) = 30입니다. E1 §4-2가 동일한 유형의 문서 자체 산술 불일치("14+4=18" 표기, 실제 22개)를 만났을 때와 같은 방식으로 처리했습니다 — 절삭 대신 완전한 6×5=30을 그대로 만들었고, 여기에 불일치를 기록해 둡니다.

### 11-5. 청취 요청

`scripts/listeningSet.ts`의 출력(§11-1[9], 스크래치패드 경로 또는 `npm run listening-set`으로 재생성)과 §8-2 체크리스트를 하루 님께 전달합니다.

**코드 작업은 여기까지이고, 판정은 청취입니다.** 30곡(워크스페이스당 6곡)을 수노에 직접 넣어 들어보시고, 문제가 발견되면 §8-4가 정한 대로 해당 워크스페이스의 문서(B1/B2/C1/C2/D1/D2/E1/F1)로 되돌아가겠습니다.
