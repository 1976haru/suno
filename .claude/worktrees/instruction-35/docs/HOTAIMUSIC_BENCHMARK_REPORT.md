# HotAIMusic 벤치마크 리포트

지시문 06의 목표: HotAIMusic의 "생성 → 여러 결과 듣기 → 선택 → 다운로드 → 영상 제작" 흐름을 흡수하되, 이 앱의 18곡 세트 설계와 품질관문(관문 1/2, release readiness)은 그대로 유지한다. 이 문서는 지시문 06/07 작업 후 실제로 어디까지 왔는지, 무엇이 여전히 격차인지 정직하게 기록합니다.

## 흐름별 대조

| HotAIMusic 단계 | 이 앱의 실제 현황 | 격차 |
|---|---|---|
| **생성** | 텍스트(가사/스타일 프롬프트)는 실제로 자동 생성됨 (관문 1/2 통과 후). 실제 음원 렌더링은 Suno 웹사이트에서 **사람이 수동으로** 수행 — `core/musicGenerationProvider.ts`가 실제 계약을 제공하지만, 이 코드베이스 어디에도 실제 Suno API 접근이 없다는 것을 조사로 확인함(2026-08 기준). | 실제 Suno API/합법적 연결 수단이 확보되면 `MusicGenerationProvider`의 진짜 구현체를 붙일 수 있는 자리는 이미 준비됨. |
| **여러 결과 듣기** | `core/audioTakes.ts`(기존, v3.74)의 실제 다중 테이크 저장/분석 + `components/AudioAnalysisPanel.tsx`의 실제 업로드 UI가 이미 동작. 지시문 06이 clipping/무음/근사 loudness/스테레오 폭/샘플레이트/채널 측정을 추가. | 테이크별 좋음/보통/별로 평가 + 탈락 사유 UI는 핵심 로직(`core/audioTakeSelection.ts`)만 완성 — 전용 비교 화면(다중 테이크 나란히 재생) 배선은 후속 과제로 명시적으로 남김. |
| **선택** | `setAdopted()`(트랙당 1개만 최종 선택 보장, 기존) + `evaluateTakeSelectionSafety()`(지시문 06 신규 — 측정값 없는 테이크/클리핑된 테이크는 선택 차단, 보컬 성별 불일치는 항상 경고 표시)로 실제 안전장치 확보. | 없음 — 이 축은 실질적으로 완성. |
| **다운로드** | `core/productionBundle.ts`(지시문 06 신규)가 `audio/lyrics/srt/thumbnails/metadata/timeline.csv/manifest.json` 실제 폴더 구조를 조립하고, 확장된 `buildZip`으로 하나의 zip으로 묶음. | 실제 오디오 바이트는 이 앱이 저장하지 않으므로(측정값만 보관), 다운로드 시점에 호출자가 실제 Blob을 들고 있어야 함 — 문서화된 설계 결정. |
| **영상 제작** | CapCut용 `timeline.csv`(누적 start/end), ffmpeg concat manifest, SRT(기존 `core/srtExport.ts` 재사용) 모두 실제로 생성됨. | 썸네일은 실제 이미지 바이트가 아니라 외부 이미지 생성 도구에 넣을 프롬프트 텍스트만 제공(기존 `thumbnailSpec.ts`의 설계를 그대로 계승) — 이미지 자체를 만드는 기능은 원래 범위 밖. |

## 유지된 것 (흡수 과정에서 훼손되지 않았는지 확인)

- **18곡 세트 설계**: `preallocateSongSlots`/`designGate`/`compositionScorer` 등 관문 1/2 로직은 지시문 06/07에서 전혀 수정하지 않음 — 전 구간 회귀 테스트(302개 파일)로 확인.
- **품질관문**: Release Readiness V2(지시문 05)와 지시문 06의 오디오 컴플라이언스 체크는 서로 다른 축(텍스트 vs 실제 음원)으로 병렬 존재 — 하나가 다른 하나를 대체하지 않음.
- **워크스페이스 격리**: 오디오 테이크/평가/러닝 시스템 모두 기존 `workspaceScope.ts`의 `scopeFilter` 규칙을 그대로 따름 (신규 저장소 없음, 기존 저장소 확장만).

## 결론

핵심 로직(측정/컴플라이언스/선택안전장치/블라인드 벤치마크/안전한 학습/생산 번들)은 실제로 동작하고 테스트로 검증됨. 남은 실질적 격차는 두 가지뿐: (1) 실제 Suno API 연결 — 이 앱의 권한 밖의 사실(사용자가 합법적 연결 수단을 제공해야 확인 가능), (2) 테이크 비교 전용 UI 화면 — 로직은 준비됐으나 화면 배선은 후속 작업.
